# BDF Gestion – Digitale Verwaltung für Stickereibetriebe

## Projektbeschreibung

BDF Gestion ist eine von mir entwickelte Anwendung zur Digitalisierung und Verwaltung von Stickereibetrieben in Guinea.

Die Anwendung unterstützt die Organisation von Aufträgen, die Verwaltung von Einnahmen und Ausgaben sowie die Auswertung betrieblicher Aktivitäten.

## Hauptfunktionen

- Verwaltung von Kundenaufträgen
- Erfassung von Einnahmen und Ausgaben
- Rollenbasierter Zugriff für Mitarbeiter und Administratoren
- Verwaltung verschiedener Stickereieinheiten
- Erstellung von Berichten und Übersichten
- Zentrale Datenspeicherung mit Firebase Realtime Database

## Verwendete Technologien

- **Flutter & Dart:** Entwicklung der Anwendung
- **Firebase Realtime Database:** Datenspeicherung
- **Android & Web:** Unterstützte Plattformen

## Meine Rolle

Eigenständige Konzeption, Entwicklung und Umsetzung der Anwendung.

## Projektziel

Digitalisierung betrieblicher Prozesse, Verbesserung der Transparenz und Vereinfachung der Verwaltung kleiner Unternehmen in Afrika.
